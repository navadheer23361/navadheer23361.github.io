01 / DEEP LEARNING · MEDICAL IMAGING

Medical Image Fusion via Diffusion Models & Attention-based Feature Fusion

A deep learning framework that fuses multimodal medical images (e.g. MRI + CT) using diffusion-based progressive denoising and attention-guided feature combination — preserving diagnostic detail across imaging modalities.

PyTorch Diffusion Models U-Net Attention Mechanisms OpenCV NumPy Medical Image Processing
  • Built a dual U-Net architecture with frozen encoders to extract complementary latent features from multiple imaging modalities simultaneously.
  • Designed an attention-based fusion module that combines modality-specific representations while preserving structural and diagnostic context.
  • Applied diffusion modelling for progressive denoising and image refinement, improving visual consistency of fused outputs.
  • Quantitatively evaluated with SSIM, PSNR, entropy, and mutual information metrics alongside qualitative visual analysis.

03 / EMBEDDED SYSTEMS · HCI · HARDWARE

SpheriSense: Spherical Multimodal Haptic Interface

A spherical, sensor-fused haptic device designed for intuitive human–computer interaction — combining motion tracking, wireless communication, and tactile feedback in a fully fabricated prototype.

ESP32 SolidWorks ESP-NOW BLE IMU (MPU6050) Haptic Motors Python Dashboard
  • Designed complete CAD models in SolidWorks and engineered electronic schematics integrating ESP32, MPU6050 IMU, and haptic actuators.
  • Implemented dual wireless protocols (ESP-NOW for low-latency data + BLE for device connectivity), achieving real-time sensor transmission.
  • Built a live dashboard for visualising motion data and haptic feedback signals, enabling interactive debugging and user testing.
  • Fabricated and tested a fully working prototype capable of 3-axis motion tracking and programmable tactile feedback response.
